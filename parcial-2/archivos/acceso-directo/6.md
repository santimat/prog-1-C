# Se tiene un archivo binario productos.dat que contiene registros ingresados de forma desordenada a lo largo del tiempo, siendo la estructura del registro la siguiente

```C
typedef struct {
int cod_producto;
char descripcion[40];
int stock_actual;
int punto_reposicion;
} producto_t;
```

Luego, existe un archivo de texto indice.txt que contiene la ubicación de cada producto dentro del archivo binario:

Ejemplo
indice.txt:
4820 0
1593 48
9021 96

Se pide desarrollar un programa que solicite al usuario el ingreso por teclado de códigos de producto a consultar (finaliza con código 0). Por cada código ingresado:
Leer secuencialmente el archivo indice.txt para encontrar el código.
Si se encuentra, leer el registro Producto accediendo de manera directa. Si stock_actual < punto_reposicion, anexar (append) de forma secuencial los datos del producto al final de un archivo de texto compras.txt con el formato:
Comprar &lt;descripcion&gt;: Faltan &lt;punto_reposicion - stock_actual&gt; unidades.

Ejemplo
compras.txt:
Comprar JABON LIQUIDO 200ML: Faltan 200 unidades.
Comprar SUAVIZANTE 1L: Faltan 127 unidades.
Comprar DETERGENTE 500ML: Faltan 148 unidades.

Si el código no está en el índice, mostrar un mensaje de error por pantalla.
